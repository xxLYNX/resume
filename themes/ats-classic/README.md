# ats-classic theme

Same layout and sections as **classic**, with contact links typeset using **visible values** (email address, URLs without `https://`) instead of short labels (`Email`, `LinkedIn`, …). Links use `\contactLink` / `\contactUnderline` (ulem + `\strut`) so underlines share one baseline. Body font is LaTeX default **Computer Modern** (10pt/11pt article class, contact line uses 9pt `\small`). Intended for uploads to scanners that extract plain text from the PDF body.

Choose this theme in the Resume tab preview theme dropdown before building or submitting.
